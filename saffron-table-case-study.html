Restaurant website · Independent concept project

A warm digital front door for a neighbourhood restaurant.

A restaurant website concept that brings atmosphere, menu discovery and reservation intent together in one welcoming experience.

ProjectSaffron Table
DisciplineRestaurant website
Built withHTML · CSS · JavaScript

The brief

Make the restaurant's identity and food photography lead the experience while keeping menu browsing and reservation requests easy to find.

This is an independent portfolio concept created to demonstrate interface design and frontend implementation. It is not presented as commissioned client work.

Key features

  • Immersive restaurant hero and brand story
  • Menu categories for small plates, mains and desserts
  • Interactive tasting list
  • Reservation request form with guest and time selections

Visual direction

A warm cream base, deep olive, saffron-rust accents and expressive serif headlines create an inviting dining identity.

Implementation

The experience is implemented as a responsive, self-contained website using HTML · CSS · JavaScript. Layouts adapt across mobile and desktop, with interactions handled in the browser.

Demo limitations: Menu items, prices and opening times are illustrative. Reservation requests are not transmitted to a restaurant or booking platform.
