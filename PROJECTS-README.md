# Four Real-World Business Website Concepts

This branch contains four independent, responsive business website demos built as portfolio case-study projects.

> These are fictional concept brands created for demonstration. No real client relationship, sales, bookings, property availability, or business results are implied.

## Projects
- `projects/maison-thread/` — fashion e-commerce storefront with category filters, search, cart count, and product interactions.
- `projects/fieldstone-realty/` — real-estate discovery with filters, property details, and enquiry form.
- `projects/saffron-table/` — restaurant site with menu categories, order basket, and table booking form.
- `projects/form-and-field/` — interior design studio portfolio with project filters, detail views, and consultation form.

Each project is currently a self-contained HTML demo. Forms provide front-end demo feedback only; no backend service is connected. The projects are isolated from the live homepage until reviewed and intentionally linked.
