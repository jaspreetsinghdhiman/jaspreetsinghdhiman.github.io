# Google Search Console — setup for Jaspreet Singh

This means Google Search Console, not the browser developer console. You do not need to paste SEO code into Chrome Console.

1. Deploy this ZIP's files to the repository root, not inside a subfolder.
2. Open https://search.google.com/search-console/ and add a URL-prefix property: https://jaspreetsinghdhiman.github.io/
3. Choose HTML file verification if offered. Google gives you a unique HTML filename and contents. Upload that exact file to the repository root, wait for deployment, then click Verify. Do not rename it. No fake verification token is included here.
4. Alternatively use Google's exact HTML verification meta tag in the index.html head. Send the real tag/file if you want help integrating it. Never send your Google password.
5. Open Sitemaps and submit sitemap.xml. Its full URL is https://jaspreetsinghdhiman.github.io/sitemap.xml
6. Use URL Inspection for the homepage, About, Work and each article. Run Test live URL, review accessibility to Google, then Request indexing where offered.
7. Watch Page indexing and Performance reports. Review actual queries containing Jaspreet Singh and Frontend Developer. Check the reported canonical agrees with your HTTPS GitHub Pages URL.
8. Keep the verification file/tag after verification.

## Honest expectations
Technical SEO and consistent identity help search engines understand this portfolio; no one can guarantee first place for a common name. Indexing and rankings depend on crawling, competition, content relevance and genuine links. Avoid fake backlinks, hidden keywords and repeated keyword stuffing.

## Before requesting indexing
Check every page in a browser, then inspect Chrome DevTools Console and Network for actual errors. Test keyboard access, touch task controls, local storage, external API failures and email handoff. No console commands are required to enable SEO.
