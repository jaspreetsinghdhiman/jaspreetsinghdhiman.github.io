Project overview

Budget Ledger is a personal portfolio demo built to demonstrate practical frontend implementation. It is not presented as commissioned client work. A browser-based expense tracker for recording spending, reviewing current-month category totals and exporting entries as CSV.

Project status: Independent personal portfolio demonstration.

Problem being addressed

Small personal expense logs are easy to abandon when adding entries takes too many steps or spending patterns are hard to scan.

Design and UX decisions

The demo uses a compact form for amount, date, category and note, then shows a monthly total, category bars and recent entries.

Main features

  • Add expenses
  • monthly total
  • category summaries
  • recent entries
  • CSV export
  • browser localStorage.

Implementation approach

Records are stored as JSON in localStorage. Monthly totals and category sums are derived from the stored entries; CSV is generated in the browser using a downloadable Blob.

Frontend technologies

HTML5, CSS3, vanilla JavaScript, localStorage, Blob and CSV download.

Responsive behaviour

A breakpoint at 800px changes the main two-column layout for narrower screens.

Challenges and technical decisions

The summary is derived from saved entries to avoid separate totals drifting out of sync. Dates are normalised to local calendar dates before month filtering.

What visitors can test

Add expenses with different dates and categories, review the month total and category bars, then export a CSV.

Open Budget Ledger demo ↗

Limitations

This is not a banking or accounting service. It has no account login, bank connection, server sync, encryption layer or multi-currency support. Data can be lost if browser storage is cleared.

Future improvements

Editing entries, date filters, configurable categories, import/restore and improved storage error states.
