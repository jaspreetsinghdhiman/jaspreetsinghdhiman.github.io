Project overview

TaskFlow is a personal portfolio demo built to demonstrate practical frontend implementation. It is not presented as commissioned client work. A vanilla JavaScript Kanban board for organising tasks across To Do, In Progress and Done with priority labels and multiple status controls.

Project status: Independent personal portfolio demonstration.

Problem being addressed

A task list is harder to scan when work has different stages and urgency. Three workflow columns give each task a visible status.

Design and UX decisions

The three columns communicate workflow state; priority labels add a second cue. Drag-and-drop supports direct manipulation, while a labelled status selector offers a keyboard-operable alternative.

Main features

  • Create tasks
  • low/medium/high priority
  • To Do, In Progress and Done
  • drag-and-drop
  • status selector
  • delete tasks
  • live counts
  • localStorage.

Implementation approach

Tasks are objects containing ID, text, priority and status. Rendering groups tasks by status. Drag events and the status selector both update the same status field.

Frontend technologies

HTML5, CSS3, vanilla JavaScript, HTML Drag and Drop API and localStorage.

Responsive behaviour

The board switches from three columns to one at 820px.

Challenges and technical decisions

The status selector avoids making drag-and-drop the only way to move a card. Task text is escaped before being inserted into the interface.

What visitors can test

Create tasks with different priorities, move them by dragging or using the status selector, delete one, and reload.

Open TaskFlow demo ↗

Limitations

This local demo has no collaboration, accounts, notifications, due dates, attachments or server synchronisation. Drag support varies by input method.

Future improvements

Task editing, due dates, filters, keyboard shortcuts, screen-reader announcements and export/backup.
