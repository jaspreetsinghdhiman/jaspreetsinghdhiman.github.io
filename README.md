## About this repository

This repository contains the source for my portfolio website, published with GitHub Pages.

Upload every website file to the repository root. Original inline styles are retained; `quality-fixes.css` and `quality-fixes.js` must also remain in the root.

### GitHub Pages deployment

In **Settings → Pages**, choose **Deploy from a branch**, select `main`, and select `/(root)`.

Preview locally with:

```bash
python3 -m http.server 8000
```

See [TESTING-REPORT.md](TESTING-REPORT.md) for the documented test scope and [SEARCH-CONSOLE-SETUP.md](SEARCH-CONSOLE-SETUP.md) for Google verification steps. Search rankings are not guaranteed. Keep a backup before making structural changes.
