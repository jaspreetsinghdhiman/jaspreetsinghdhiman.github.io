# Jaspreet Singh — Portfolio

A lightweight, GitHub Pages-compatible frontend developer portfolio built with HTML, CSS and JavaScript.

## Local preview
Open `index.html`, or run `python3 -m http.server 8000` and visit http://localhost:8000

## GitHub Pages deployment
1. Push the contents of this folder to the root of the `jaspreetsinghdhiman.github.io` repository.
2. Go to Settings → Pages.
3. Choose “Deploy from a branch”, branch `main`, folder `/ (root)`.
4. Save and wait for deployment.
5. Visit https://jaspreetsinghdhiman.github.io/

## Notes
- Experience is calculated dynamically from August 2025.
- The contact form uses an encoded `mailto:` link; visitors must press Send in their email application.
- No phone number, company details, fake testimonials, fake statistics or unverified project links are displayed.
