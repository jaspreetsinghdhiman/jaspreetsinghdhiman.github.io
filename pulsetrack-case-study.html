Project overview

PulseTrack is a personal portfolio demo built to demonstrate practical frontend implementation. It is not presented as commissioned client work. A lightweight income and expense tracker with category totals, a canvas-based spending chart and browser-local persistence.

Project status: Independent personal portfolio demonstration.

Problem being addressed

A personal ledger should distinguish money coming in from money going out and show where expenses are grouped.

Design and UX decisions

Three summary figures show income, expenses and balance. A transaction type toggle and category selector structure entry, while the canvas chart visualises category spending.

Main features

  • Add income and expenses
  • choose categories
  • view totals and balance
  • category summary
  • Canvas chart
  • localStorage.

Implementation approach

Transactions are stored as objects in localStorage. Totals are derived by transaction type; category spending is aggregated and drawn with the Canvas 2D context.

Frontend technologies

HTML5, CSS3, vanilla JavaScript, Canvas 2D API and localStorage.

Responsive behaviour

The main grid and summary cards become single-column at 820px; the canvas is constrained to its container width.

Challenges and technical decisions

Balance is calculated as income minus expenses rather than stored separately. The chart is redrawn from transaction data after updates.

What visitors can test

Add income and expenses in several categories, compare totals and balance, inspect the chart, then reload.

Open PulseTrack demo ↗

Limitations

This is not financial advice or accounting software. It has no authentication, cloud sync, recurring transactions, budgets, bank integration or multi-currency support.

Future improvements

Date filters, editing, CSV export, accessible chart text and backup/restore.
