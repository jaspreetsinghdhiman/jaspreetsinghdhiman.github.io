Interior design studio · Independent concept project

A visual portfolio for a thoughtful interiors studio.

A design-led studio website concept built to showcase completed spaces, communicate process and encourage considered project enquiries.

ProjectForm & Field
DisciplineInterior design studio
Built withHTML · CSS · JavaScript

The brief

Present a portfolio with strong imagery and enough project context to help prospective clients understand the studio's approach and start a conversation.

This is an independent portfolio concept created to demonstrate interface design and frontend implementation. It is not presented as commissioned client work.

Key features

  • Editorial studio homepage and positioning
  • Filterable residential, hospitality and workspace projects
  • Large image previews with lightbox interaction
  • Three-step studio process and project enquiry form

Visual direction

Muted olive, sand and warm neutral tones pair with elegant serif typography and generous image-led layouts to make the work feel central.

Implementation

The experience is implemented as a responsive, self-contained website using HTML · CSS · JavaScript. Layouts adapt across mobile and desktop, with interactions handled in the browser.

Demo limitations: Project names and imagery are illustrative concept content. The enquiry form demonstrates front-end validation and feedback only; no message is sent.
